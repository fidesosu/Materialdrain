# Materialdrain

Materialdrain is an Android app for Pixeldrain and other file hosts: WebDAV, S3, SMB shares, and any REST API described
by a [provider config](provider-configuration.md).

These pages are for developers: where things are in the code, how they work, and why they're done the way they are.

!!! note "Being written"
    The developer documentation is being written. For now, see [Provider configuration](provider-configuration.md) for
    how hosts are described.
