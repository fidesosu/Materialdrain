# Materialdrain

Materialdrain is an Android app for your files on [Pixeldrain](https://pixeldrain.com) and on other hosts: a
Nextcloud or other **WebDAV** server, an **S3** bucket, a Windows or NAS **SMB** share, or any **REST API** you
describe in a small JSON file. Browse, upload, download, preview, search, share and organise them, all from one app,
in Material 3.

[Download the app](https://materialdrain.senko.tools/){ .md-button .md-button--primary }
[Source code on GitHub](https://github.com/fidesosu/Materialdrain){ .md-button }

## What it can do

| | |
| --- | --- |
| **Hosts** | Pixeldrain (built in), WebDAV, S3, SMB, and any REST API, side by side. Switch between them at the top of the screen |
| **Browsing** | A folder browser, a flat list of all your files, and Pixeldrain's lists, each sortable by name, size or date, as rows or :nightly: a grid of pictures, chosen for each folder |
| **Search** | Searches the open folder *and every folder under it*, with results as you type |
| **Uploads** | Several files at once, from the app or shared from any other app, optionally in the order they were last changed |
| **Downloads** | Into your Download folder, with progress, cancelling, and opening the file when it's done. Whole folders :nightly:, file by file or as one zip |
| **Previews** | Images (HEIC, AVIF and animated ones too), video and audio with seeking, text and code with colours, Markdown :nightly:, PDFs, and the contents of archives |
| **Music** :nightly: | Songs go on in the background, with a miniplayer, a player with a queue, and controls on the lock screen |
| **Thumbnails** | Photos, video frames and album covers, even from hosts that make none themselves |
| **Background** | Transfers keep going with the app closed, with a notification to follow and cancel them |
| **Your phone** :nightly: | Your hosts in the system's file picker, Pixeldrain links opening in the app, a Quick Settings tile, and your own colours |
| **Privacy** | Sign-ins are encrypted on the device, never part of a config, and the app can be locked with your fingerprint |
